#  Wine Quality - Exploratory Data Analysis (EDA)

Bu projede, şarapların kimyasal özellikleri ile kalite puanları arasındaki ilişkiyi incelemek amacıyla **Keşifsel Veri Analizi (EDA)** gerçekleştirilmiştir.

## 📊 Yapılan Çalışmalar

- **Veri Yapısının İncelenmesi:** Veri boyutları (`shape`), değişken tipleri (`info`) ve istatistiksel özetler (`describe`) çıkarıldı.
- **Veri Kalitesi Kontrolü:** Eksik değer (`isnull`) ve tekrar eden satır (`duplicated`) kontrolleri yapıldı.
- **Korelasyon Analizi:** Değişkenler arasındaki pozitif ve negatif ilişkiler korelasyon matrisi ve Isı Haritası (*Seaborn Heatmap*) ile görselleştirildi.
- **Görselleştirmeler:** 
  - Kalite sınıf dağılımları (Bar Plot)
  - pH değerlerinin dağılımı (Histogram)
  - Tüm değişkenlerin birbiriyle ilişkisi (PairGrid)

##  Kullanılan Teknolojiler

- **Python**
- **Pandas** (Veri manipülasyonu)
- **Matplotlib & Seaborn** (Veri görselleştirme)
